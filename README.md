# 🌱 Renewable Energy Adoption Analysis

## 📌 Project Overview

This project explores renewable energy-related indicator data across countries and over time using Python. It focuses on data cleaning, exploratory data analysis (EDA), statistical summaries, and visualizations to identify patterns and differences between countries and regions.

## 🎯 Objectives

- Analyze how the indicator changes over time.
- Compare average indicator values across countries and regions.
- Visualize year-wise trends using line charts.
- Explore statistical relationships between years and indicator values.
- Practice real-world data analysis using Python.

## 📂 Dataset

The dataset contains the following columns:

| Column | Description |
|---|---|
| `Country Name` | Name of the country or region |
| `Country Code` | Identifier for the country or region |
| `Year` | Year of observation |
| `Value` | Recorded indicator value |

**Note:** Confirm the original source and definition of the indicator before interpreting its units or describing it as a percentage.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## 🔍 Project Workflow

1. Load the dataset.
2. Inspect columns, data types, and missing values.
3. Clean duplicate and incomplete records.
4. Analyze yearly trends.
5. Compare indicator values across countries and regions.
6. Explore correlations and statistical summaries.
7. Visualize findings using graphs and charts.

## 📊 Key Analysis

- Year-wise indicator trend analysis
- Top and bottom entries by average indicator value
- Country-wise comparisons over time
- Correlation analysis
- Summary statistics, including mean, median, minimum, and maximum

## 📈 Expected Outcomes

The analysis helps explore how the recorded indicator varies across years and countries. Visualizations make patterns and differences easier to understand.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
3. Upload the dataset file.
4. Update the dataset path in the notebook if needed.
5. Run the notebook cells in order.
